# max-fitness-today

Public. The workout page and program that Max's Day Brief and phone read (GitHub Pages).

- Shared rules: read `CORE.md` in the `max-system` repo first. If you can't reach it, say so and stop.
- This repo's plan and status: `PLAN.md` and `STATUS.md` (add them when the Fitness project creates them).
- Before every push, read your own diff for keys, tokens, account numbers and health details.

## This repo is public
Anyone can read everything here, including old versions. Only the program and the page go in it. Never add:
- workout logs or weights lifted
- the knowledge base, transcripts or notes from videos
- health details, or the name of an injury or a condition, even inside the program text
- keys, tokens, email addresses or account names
